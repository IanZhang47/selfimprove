# Sacred and Foundational Texts as Literature

[Literature guide](00-READING-GUIDE.md) · [My study plan](../01-MY-STUDY-PLAN.md) · [Subject map](../03-SUBJECT-MAP.md)

**Catalog status:** Candidate unless a linked source record identifies a specific check. [How to use these labels](00-READING-GUIDE.md#source-status).

These texts can be studied as literature, within living religious traditions, and through history, philosophy, and religious studies. Identify which question you are asking. Do not treat a text as a transparent description of everyone in a tradition, or equate literary interpretation with evidence for or against a theological claim.

| Text | Translation |
|---|---|
| Hebrew Bible | Robert Alter — a literary translation with commentary. Start with Genesis, Job, Ecclesiastes, Psalms, Song of Songs |
| New Testament | The Gospels; David Bentley Hart for a deliberately unsmoothed rendering |
| Qur'an | M.A.S. Abdel Haleem (Oxford) |
| *Bhagavad Gita* | Barbara Stoler Miller |
| *Dhammapada* | Gil Fronsdal |
| 《论语》 | Chinese candidate if accessible: 杨伯峻《论语译注》(中华书局); otherwise select a scholarly annotated translation |
| 《庄子》 | Chinese candidate if accessible: 陈鼓应《庄子今注今译》; compare commentary with an annotated translation as needed |
| 《道德经》 | Chinese candidate if accessible: 陈鼓应《老子今注今译》. In any language, identify the source text, translator, and distinction between translation and paraphrase |
