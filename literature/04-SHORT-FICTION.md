# Short Fiction

[Literature guide](00-READING-GUIDE.md) · [My study plan](../01-MY-STUDY-PLAN.md) · [Subject map](../03-SUBJECT-MAP.md)

**Catalog status:** Candidate unless a linked source record identifies a specific check. [How to use these labels](00-READING-GUIDE.md#source-status).

Short fiction often allows a complete work within one or a few sessions. Reading time depends on length, language, difficulty, and the attention you want to give.

| Writer | Start with |
|---|---|
| Chekhov | *The Lady with the Dog*, *Ward No. 6*, *The Bishop* |
| Borges | *Ficciones*; for Andrew Hurley’s translations, use the relevant section of *Collected Fictions* ([S6](12-SOURCE-REGISTER.md#s6), source-checked) |
| Kafka | *A Hunger Artist*, *In the Penal Colony*, *The Metamorphosis* |
| Joyce | *Dubliners* — read *The Dead* last |
| Lu Xun | *Diary of a Madman*, *Kong Yiji* |
| Isaac Babel | *Red Cavalry* |
| Katherine Mansfield | *The Garden Party* |
| Flannery O'Connor | *A Good Man Is Hard to Find* |
| Alice Munro | *Runaway*, *Dear Life* |
| Grace Paley | *The Little Disturbances of Man* |
| Denis Johnson | *Jesus' Son* |
| Lydia Davis | *Collected Stories* |
| George Saunders | *Tenth of December* |
| Clarice Lispector | *Complete Stories* |

**Anthologies:** *The Norton Anthology of Short Fiction*; Saunders, *A Swim in a Pond in the Rain* (a writer’s teaching approach to seven Russian stories; a candidate companion, not a definitive theory of the form).
